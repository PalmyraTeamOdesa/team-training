# TRITON Team — тренування

Застосунок команди TRITON Triathlon Team (Одеса): план тренувань, щоденник, харчування, командна стрічка і кабінет тренера.
Статичний PWA (GitHub Pages) + Supabase (Auth, Postgres з RLS, Storage, Edge Functions).

**Живий сайт:** https://palmyrateamodesa.github.io/team-training/

## Структура
- `src/` — код застосунку (звичайний JS, без фреймворку). Порядок збирання — у `build.mjs`.
  - `core.js` — константи, бібліотека з 79 тренувань, парсер їжі
  - `num.js` — поле «цифра + повзунок»
  - `plan.js` — генератор тижня, графіки, експорт .zwo
  - `data.js` — робота з Supabase, зберігання планів
  - `athlete.js`, `team.js`, `food.js`, `prog.js` — вкладки спортсмена
  - `coach.js` — кабінет тренера
  - `onb.js` — анкета (8 кроків)
  - `files.js` — стиснення фото, читання .fit/.gpx/.tcx
  - `misc.js` — профіль, налаштування, асистент
- `public/` — index.html, service worker, маніфест, іконки
- `supabase/migrations/` — схема бази, політики RLS, тригери
- `supabase/functions/` — Edge Functions `ai-assistant` (xAI Grok) і `account` (реєстрація, скидання пароля тренером)

## Збирання
```
npm ci
npm run build   # результат у dist/
```
Кожен push у `main` автоматично публікує сайт (GitHub Actions → Pages).

## Ролі і безпека
- Тренер — лише акаунт, записаний у таблицю `coaches` (тільки через SQL у Supabase; з застосунку призначити неможливо).
- Нові учасники мають статус `pending`, доки тренер не прийме їх у команду.
- Спортсмен бачить лише свої дані; команда бачить лише те, чим поділились (стрічка, чат, рейтинг).
- У фронтенді лише публічний ключ (publishable). Сервісний ключ живе тільки в Edge Functions.

## Асистент АІ
Edge Function `ai-assistant` викликає xAI API (`https://api.x.ai/v1/chat/completions`). Ключ береться на сервері: з Supabase Vault (секрет `xai_api_key`, читається лише service role через `get_app_secret`) або з секрету Edge Function `XAI_API_KEY`. Модель — Vault `xai_model` / `XAI_MODEL`, типово `grok-4.20-0309-non-reasoning`. Ліміти: 30 запитів на день для спортсмена, 100 для тренера, до 350 токенів у відповіді. Тривожні симптоми не витрачають ліміт і йдуть тренеру.

Зберегти ключ у Vault (SQL Editor у Dashboard): `select vault.create_secret('КЛЮЧ','xai_api_key');`
Без ключа застосунок показує «АІ ще не підключено». Додати: Supabase → Edge Functions → Secrets.

## Харчування
Локальна база ~370 продуктів і страв (`src/fooddb.js`): українські страви, фастфуд, напої, алкоголь, солодощі, спортивне харчування; синоніми українською/російською/англійською, відмінки, одиниці (г/гр/грам, мл, л, шт, склянка, ложка, порція, тарілка, шматок, келих, пляшка).
Те, чого немає в базі, оцінює Edge Function `food-estimate` (той самий ключ xAI): строгий JSON, кеш однакових запитів у `food_cache`, окремий ліміт 60 оцінок на день. Такі позиції позначені «≈ оцінка АІ», грами й калорії можна виправити перед збереженням.

## Ролі та секції
- **Адміністратор** — єдиний акаунт у таблиці `coaches` (killeroftheroad@gmail.com): підтверджує людей, призначає тренерів секцій, додає спортсменів у секції, створює акаунти (Edge Function `account`, дія `admin_create_user`).
- **Тренер секції** — звичайний підтверджений акаунт із записом у `section_coaches`. Пише дошку своєї секції, ставить бали/реакції/досягнення секції, бачить лише спортсменів своїх секцій; повне навантаження з інших видів — лише якщо сам увімкнув перемикач для спортсмена (`coach_athlete_prefs`, видно тільки йому). Додавати людей і тренерів не може (RLS + перевірка у функції).
- **Секції**: Велоспорт, Плавання, Біг (`sections`, `section_members`). Дошка: `board_posts` (план на дату), `board_lines` (рядок для спортсмена), `board_marks` (✅/❌/🔁 + коментар, час, дистанція, пульс), `board_comments`, `board_points`, `board_templates`. Рейтинги: `section_rating(sec, тиждень)` і `club_rating(місяць)`.
- Якщо спортсмен у секції з тренером, автоплан для цього виду спорту вимикається (у плані — «план тренера секції»).

## Люди (адмін)
«Запросити за посиланням» — основний спосіб додати людину: копіювання, «Надіслати в Telegram» або системне «Поділитися». Посилання відкриває реєстрацію (`#i` або `#i=bike,run`); після анкети заявка чекає підтвердження в «Нові заявки» (без автопідтвердження). Опційно можна заздалегідь обрати секції, які застосуються після вашого «Прийняти». Після першого входу вже підтвердженого спортсмена пропонується встановити застосунок (або лишитися в браузері); у Telegram показується підказка відкрити в Chrome/Safari.
Системна кнопка «Назад» на Android спочатку закриває аркуш, потім повертає попередню вкладку чи кабінет; на головному екрані перше натискання показує «Натисніть ще раз, щоб вийти».

Вкладка адміна «Люди» (`src/people.js`): пошук, фільтри за секціями/ролями, порядок — адмін, тренери, учасники (за алфавітом). Картка людини: «Написати» (особистий чат), «Зробити тренером» (будь-яка комбінація секцій одним збереженням, `admin_set_roles`), нагороди (бали, 🔥 похвала, досягнення, приз; тренер секції — лише своя секція), навантаження й профіль, скидання пароля, «Пауза» (`admin_set_paused`: ховає з дошок і рейтингів, обернено) і «Виключити з команди» (`admin_expel`: прибирає з секцій, закриває доступ, блокує вхід; історія лишається; `admin_restore` повертає).
Адмін теж може бути спортсменом і тренером у секціях: перемикач «Мій кабінет спортсмена» / «Режим адміністратора» у шапці. Нових (pending) і виключених користувачів RLS (`private.is_blocked`, restrictive-політики `blocked_deny`) і функції `ai-assistant`/`food-estimate` не пускають ні до чого, крім їх власного статусу (і чату з адміном).

## Іконки
`python3 tools/make_icons.py <лого.jpg> --preview preview.png` — обрізає круглий логотип і створює `public/icons/` (192/512, maskable, apple-touch-icon, favicon, logo-256). Після цього збірка сама показує лого на екрані входу і оновлює кеш service worker.

## Встановлення на екран
У Chrome (Android і комп’ютер) знову працює власна пропозиція встановити. Після входу також є банер: «Встановити», якщо Chrome дав подію, інакше «Як встановити» (меню ⋮ → «Додати на головний екран»). Той самий пункт є в меню профілю (аватар). На iPhone додається через Safari: Поділитися → «На екран Додому» (інструкція в тому ж пункті меню). Якщо відкрито в Telegram чи Instagram — підказка відкрити посилання в Chrome або Safari. Банер можна закрити; він не показується знову близько 7 днів і ховається, коли застосунок уже встановлено.
